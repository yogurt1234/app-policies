購入・返金について

本アプリは App Store を通じた買い切り課金です。購入は Apple ID に紐づき、「購入を復元」で再ダウンロード時も復元できます。返金は Apple が管理しており、開発者側では対応できません。返金をご希望の場合は Apple のサポート（reportaproblem.apple.com）へお申し込みください。購入したのに機能がアンロックされない場合は、まずアプリ内の「購入を復元」をお試しください。

ご注意（サポート対象外）

有給休暇の残日数・失効日・付与ルール等の正確性に関するご相談は対象外です。本アプリの数値はすべて目安であり、勤務先の正式記録ではありません。正確な情報は勤務先の就業規則・人事部門・給与明細でご確認ください。
