ご利用にあたって

本アプリが表示する水やり・肥料・霧吹き・植え替えの間隔、明るさ、生育適温・越冬の目安、置き場所のアドバイスなどは、いずれも一般的な園芸情報に基づく「目安・参考値」です。

  • 実際に必要な頻度や環境は、鉢のサイズ・置き場所・室温・湿度・土の種類・季節・株の状態によって大きく異なります。リマインドは「土の乾き具合を確認するきっかけ」としてご活用ください。
  • 毒性（ペット・子ども向け）の表示は一般的な注意喚起であり、獣医学・医学的な助言ではありません。誤食・接触が疑われる場合は動物病院・医療機関・中毒110番などにご相談ください。
