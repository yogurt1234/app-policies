本プライバシーポリシーは、「介護そなえ」（以下「本アプリ」）をご利用いただくにあたり、取り扱う情報とその方針について説明するものです。

1. 事業者情報

  • アプリ名: 介護そなえ
  • 連絡先: wangjigang830@gmail.com

2. 収集する情報

本アプリは、ご利用者が手動で入力・登録した以下の情報を取り扱います。

  1. 介護を受ける方（親など）の続柄・お名前（任意）・現在の年齢
  2. 介護シナリオの前提（介護の場所・施設タイプ、要介護度、想定介護期間、介護開始までの期間、費用の前提）
  3. 親御さんの備えに関する情報（年金の月額・貯蓄などの資産・家計に関する想定値）
  4. 毎月の積立額、分担する家族の人数、ご自身の負担割合

これらの情報はすべて、ご利用者自身がアプリに入力・登録したデータです。本アプリが自動的に個人情報を収集することはありません。なお、上記には親御さんの資産・続柄など機微な情報が含まれる場合がありますが、これらも下記のとおりデバイス内にのみ保存されます。

3. データの保存場所

本アプリが取り扱うすべてのデータは、ご利用のiOSデバイス内にのみ保存されます。外部サーバーやクラウドサービスへの自動送信は一切行いません。

  1. すべてのデータはSwiftDataを使用してデバイス内に保存されます。
  2. 本アプリの開発者を含む第三者が、これらのデータにアクセスすることはできません。

4. データの外部送信・第三者提供

  1. 本アプリは、ご利用者のデータを外部サーバーへ送信しません。
  2. 本アプリは、ご利用者のデータを第三者へ提供・販売・開示しません。
  3. 本アプリは、広告配信SDK・アクセス解析ツール（Firebase、Google Analyticsなど）を一切使用していません。
  4. シェア用に作成する画像には、親御さんの実名・資産額・年金額などの機微情報や絶対額を含めない設計としています（既定では実名を表示しません）。

5. アクセス権限について

本アプリは、iOS標準のアクセス許可を必要としません。カメラ・位置情報・連絡先などへのアクセスは行いません。

7. データの保持と削除

  1. 本アプリ内のデータは、ご利用者が削除操作を行うまでデバイス内に保持されます。
  2. 本アプリをアンインストールすることで、デバイス内に保存されたすべてのデータが削除されます。
  3. 開発者側でデータを保持・管理することはないため、開発者へのデータ削除依頼は対応できません。
