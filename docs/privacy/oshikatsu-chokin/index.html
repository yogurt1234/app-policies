推し活貯金ノート プライバシーポリシー

本プライバシーポリシーは、推し活の貯金・支出を記録するアプリ「推し活貯金ノート」（以下「本アプリ」）をご利用いただくにあたり、取り扱う情報とその方針について説明するものです。

1. 事業者情報

  • アプリ名: 推し活貯金ノート
  • 連絡先: yoshiokanozomu0619.2@gmail.com

2. 収集する情報

本アプリは、ご利用者が手動で入力・登録した以下の情報を取り扱います。

  1. 推しのプロフィール: 名前・表示色（推し色）・誕生日・メモ・関連リンク
  2. 貯金目標: 目標名・目標金額・期限・内訳の項目と金額
  3. 記録: 貯金・支出・返金・調整の金額、日付、カテゴリ、タグ、メモ、参考リンクのURL
  4. 活動の記録: 日付・タイトル・本文・タグ
  5. 予定と定期: 予定支出・定期費の内容、次回日、周期、終了日、通知の設定
  6. 予算: 全体・月ごとの予算額
  7. 写真: ご利用者がフォトライブラリから選んで記録・推しに添付した画像
  8. アプリ内の設定値（通知のオン／オフ・通知時刻・金額の表示／非表示など）

これらの情報はすべて、ご利用者自身がアプリに入力・登録したデータです。本アプリが自動的に個人情報を収集することはありません。位置情報・連絡先・端末識別子などをバックグラウンドで取得することもありません。銀行口座・クレジットカード・外部の家計簿サービスと連携して取引情報を取得することもありません。

3. データの保存場所

  1. 本アプリが取り扱うすべてのデータ（記録・写真を含む）は、SwiftData を用いてご利用のiOSデバイス内に保存されます。
  2. iCloud同期を有効にしている場合、データは Apple の iCloud のプライベートデータベースを経由して、ご利用者ご自身の同じApple Accountの端末間でのみ同期されます。この領域はご利用者のApple Accountに属し、本アプリの開発者はその内容を参照できません。取り扱いは Apple のプライバシーポリシーに従います。
  3. iCloud同期が利用できない環境では、本アプリは端末内のみの保存に切り替えて動作を継続します。データが失われることはありません。
  4. アプリの設定値（通知のオン／オフ等）は、端末内の標準の設定保存領域（UserDefaults）に保存されます。
  5. ウィジェットへの表示に必要な最小限の集計値は、App Groups を通じて同一端末内でのみ共有されます。外部への送信は行いません。
  6. 本アプリの開発者を含む第三者が、これらのデータにアクセスすることはできません。

4. データの外部送信・第三者提供

  1. 本アプリは、ご利用者のデータを開発者のサーバー等へ送信しません。iCloud同期を除き、すべての処理は端末内で完結します。
  2. 本アプリは、ご利用者のデータを第三者へ提供・販売・開示しません。
  3. 本アプリは、広告配信SDK・アクセス解析ツール（Firebase、Google Analytics など）を一切使用せず、トラッキングも行いません。
  4. 記録に添付されたURLについて、本アプリがそのリンク先へ自動的にアクセスすることはありません。表示に使う見出しはURLの文字列から端末内で組み立てており、ご利用者が貼ったURLがリンク先のサーバーに知られることはありません。

5. 写真の取り扱い

  1. 本アプリはフォトライブラリ全体を読み取りません。ご利用者が選択した写真だけを受け取ります。
  2. 受け取った写真は、アプリ内で表示用に作り直したうえで端末内に保存します。このとき撮影場所（GPS）・撮影日時・機種などの元の写真のメタデータは引き継ぎません。
  3. 共有カードの画像を「写真に保存」する場合にのみ、写真ライブラリへの追加の許可を求めます。読み取りの許可は求めません。

6. アプリ内課金について

本アプリには自動更新サブスクリプション「推し活貯金ノート Pro」のApp内課金があります。購入手続き・課金・更新・解約はすべて Apple の App Store を通じて行われ、Apple が処理します。本アプリがクレジットカード番号などの決済情報を取得・保存することはありません。本アプリは Apple から購入状態（有効か否か）のみを受け取り、それをもとに機能を解放します。

7. アクセス権限について

本アプリは、以下のiOS機能へのアクセス許可を求める場合があります。それぞれの用途のみに使用し、目的外の利用は行いません。

  1. 通知: 記録のリマインダー、予定支出・定期費の予定日、推しの誕生日などをお知らせするために使用します。通知はすべて端末内で組み立てられ、外部のサーバーを経由しません。
  2. 写真（フォトライブラリ）: ご利用者が選択した写真を記録・推しに添付するため、および共有カードの画像を保存するために使用します。

これらの権限はご利用者がiOSの設定からいつでも変更・取り消しできます。

8. データの保持と削除

  1. 本アプリ内のデータは、ご利用者が削除操作を行うまで保持されます。
  2. 削除した推し・記録は一定期間「ゴミ箱」に保管され、その期間内であればご利用者ご自身で元に戻せます。期間を過ぎたものは自動的に消去されます。
  3. 本アプリをアンインストールすることで、デバイス内に保存されたデータが削除されます。iCloud同期をご利用の場合、iCloud上のデータはiOSの設定またはiCloudの管理画面から削除できます。
  4. ご利用者は、アプリ内の機能でご自身のデータをZIPファイル・CSVファイルとして書き出し、復元することができます。書き出したファイルの保管場所と共有範囲はご利用者の管理下にあります。
  5. 開発者側でデータを保持・管理することはないため、開発者へのデータ削除依頼は対応できません。

9. お子様のプライバシー

本アプリは一般のご利用者を対象としており、13歳未満のお子様からの個人情報収集を意図していません。
